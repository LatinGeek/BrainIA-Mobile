04 · Review

Review in a minute, one tap at a time

Review used to be a data-entry form with a confirm dialog at the end. It is now a short, focused session: one plain question per card, the likely answer ready for one tap or a swipe, undo instead of dialogs, repeated cases batched, and the obvious ones handled for you.

1 tapper decisionwas 4 to 7 taps plus a confirm dialog
~1 minfor a full queue of 6shown up front, before you start
0confirm dialogsevery answer is undoable for 5 seconds
12obvious matches auto-handledlisted and reversible, never silent

Start a session, then swipe or drag a card right to accept and left to skip. The same flow runs in the live prototype above, from the Revisar tab or the first highlight on Today.

05 · Components

One component system

An audit of components/ and the screen files found aliases, duplicates and local copies of shared controls. Each card is one consolidated component: what it replaces, its API and its variants, all live.

Export merged · Alias deleted, it only re-exports another name · Local private helper or defined inside a screen file
06 · Motion

Motion system

Four durations, four curves and one stagger. Motion explains where things came from, confirms an action or shows a value changing; nothing moves for decoration while you read.

07 · Foundations

Tokens

Glass adds a fill ladder, a blur scale with a solid fallback, a specular edge and an ambient light field. Semantic colours keep their names.
