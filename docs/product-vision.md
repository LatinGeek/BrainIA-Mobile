# Vision y Alcance

## Producto

BrainIA-Mobile es la compania movil de BrainIA para un usuario individual avanzado que quiere consultar su second-brain desde el telefono.

La app debe combinar:

- lectura rapida del conocimiento ya consolidado
- dashboard de insights
- dashboard financiero con resumenes mensuales, anuales, por categoria y por cuenta
- captura ligera de eventos
- revision y operacion sobre alias, merges y reprocess

## Objetivo principal

El foco principal es leer y explorar el conocimiento.

La captura existe para alimentar el backend, pero no reemplaza al dashboard como experiencia central.

## Principios

- read-first
- dashboard-first
- mobile-first
- consistente con el backend como source of truth
- poca logica de negocio en el cliente
- soporte para consultas, trazabilidad y operacion liviana

## Resultados esperados

La app debe permitir:

- entender rapidamente el estado del second-brain
- navegar el grafo y las entidades relevantes
- ver insights y digests sin entrar al backend
- revisar actividad financiera de forma resumida y detallada
- capturar eventos de forma simple desde el movil
- resolver aliases y canonicalizaciones cuando sea necesario
