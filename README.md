# BrainIA-Mobile

Aplicacion movil multiplataforma para consumir el backend de BrainIA y presentar el second-brain del usuario.

## Objetivo

La app esta pensada como un cliente movil de lectura, consulta y captura ligera para BrainIA. La experiencia principal es un dashboard de insights y finanzas, con busqueda y review como superficies secundarias.

## Stack definido

- Expo
- React Native
- TypeScript

## Decisiones de producto

- Usuario principal: power user individual
- Autenticacion: SSO o identidad de tipo empresa
- Alcance principal: lectura del second-brain
- Escribir en la app: si, pero acotado a captura y operacion
- Navegacion: tabs inferiores
- Plataforma: iOS y Android
- Offline: no como modo principal
